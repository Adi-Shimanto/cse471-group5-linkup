# CSE471 Group Project - LinkUp

## 🚀 Project Overview
LinkUp is a social matching platform developed for CSE471 group project using:

- Laravel (Backend API)
- React with Inertia.js (Frontend)
- PostgreSQL (Database)
- TailwindCSS (UI Styling)

---

## 🔥 Features (Planned Modules)

### Module 0: Authentication System
- User Registration
- Login / Logout
- Remember Me
- Auto profile creation

### Module 1: Discovery & Matching
- Quiz-based user profiling
- Personalized recommendations
- Interest-based matching

### Module 2: Newsfeed System
- Personalized posts
- Suggested users/groups
- Algorithm-based ranking

### Module 3: Search System
- Tag-based search
- Keyword search
- Filters (location/interests)

---

## 🛠 Tech Stack
- Laravel
- React (Inertia.js)
- PostgreSQL
- TailwindCSS
- Gemini / Hugging Face API (AI Matching)
- Gmail API (Notifications)
- SSLCommerz (Payments)
